# Open-source furniture models

The visible furniture in MeliCases uses original third-party models stored locally
so the game remains available offline and does not depend on a CDN.

## Kenney Furniture Kit

- Creator: Kenney (Kenney Vleugels)
- Source: https://kenney.nl/assets/furniture-kit
- License: Creative Commons Zero 1.0 (CC0)
- Imported models: bed, pillow, wardrobe, desk, tables, vanity, mirror,
  shower, toilet, kitchen cabinets, fridge, island, sofa, bookcase,
  television, rug, plant and floor lamp.
- Original license: `kenney/LICENSE.txt`

## Bicycle by Poly by Google

- Creator: Poly by Google
- Source: https://poly.pizza/m/fvrGuzZjGu2
- License: Creative Commons Attribution 3.0
- File: `poly-google/bike.glb`
- Changes: locally hosted, automatically normalized and scaled to the apartment.

The generated glTF files outside this directory remain original MeliCases assets
for technical equipment, documents, architectural fixtures and fault effects.
